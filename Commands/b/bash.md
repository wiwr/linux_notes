```bash
bash script.sh
```

`bash -x` **Runs the script normally and prints a live execution trace.**
`bash +n` **Dry-runs the script to check for syntax errors without executing code.**
```bash
bash +n -x script.sh
```

# shortcuts
`alt-f` - forward word
`alt-b` - back word
`alt-t` - swap words
`ctrl-f` - forward char
`ctrl-b` - back char
`ctrl-t` - swap char
`ctrl-w` - delete one word back (till space)
`ctrl-u` - delete entire line to left
`ctrl-k` - delete till end of line
`ctrl-r` - reverse search
